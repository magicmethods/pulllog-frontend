# FE-G4 アップロードフローとバリデーション（FE-004・FE-007統合）

## 背景
- ギャラリー資産の追加導線は未実装であり、ドラッグ&ドロップ・ファイル選択・プレビューなどの UI 要件が揃っていない。
- バリデーションエラー（409/403/422）の文言を i18n に揃えたトースト表示、アップロード後の一覧・使用量リフレッシュ、タグ入力コンポーネント（補完あり）の整備が求められる。
- バックエンドの署名付きURL仕様や容量制限に沿った UX を実現するため、進捗表示やエラーハンドリングの設計が必要。

## 対応範囲
- `components/gallery/GalleryUploadDialog.vue`（新規）を実装し、PrimeVue Dialog + DropZone（`<input type="file">` 併用）でシングル／マルチファイルアップロードに対応。
- 画像プレビュー、メタデータ入力（タイトル・説明・visibility・タグ）、バリデーションエラー表示、送信中のプログレス表示を実装。
- タグ入力コンポーネント（`components/gallery/GalleryTagInput.vue` 仮称）を共通化し、一覧側と共有できるようにする。
- アップロード成功時に FE-G2 の一覧と FE-G3 の使用量ストアを再フェッチするイベント発火を実装。
- i18n 文言の追加（フィールドラベル・エラーメッセージ・トースト文言）。

## 主なタスク
- アップロードAPI (`POST /gallery/assets`) のリクエスト仕様（FormData or JSON）を確認し、`useAPI` 内での送信方法を調整。
- プレビュー生成処理（`URL.createObjectURL` / `FileReader`）とキャンセル時のリソース解放。
- エラーコードごとの UX（例: 409=重複、403=権限なし、422=バリデーション）整理とトースト or ダイアログ表示。
- タグ補完用のデータ取得タイミング（初回表示時のフェッチ vs 入力開始時の lazy load）を決定。
- フォーム入力のアクセシビリティ（キーボード操作・スクリーンリーダー対応）確認。

## 想定変更ファイル
- `components/gallery/GalleryUploadDialog.vue`（新規）
- `components/gallery/GalleryTagInput.vue`（新規）
- `stores/useGalleryStore.ts`

- `i18n/locales/ja.ts`
- `pages/gallery/index.vue`（ダイアログ呼び出し）

## 確認事項
- アップロードは単一ファイルのみ対応でしょうか？ それとも複数ファイル一括アップロードを想定していますか？
- 画像以外のファイル形式（動画・PDF 等）は受け付けますか？ 許可 MIME タイプの一覧を確定したいです。
- タグ入力は初期リリースで必須ですか？ それとも任意入力で、後続Issue（FE-G5）まで非表示にしておきますか？
- プログレス表示は全体の進捗バーのみで十分ですか？ ファイルごとの詳細進捗を表示しますか？
- 失敗時のリトライは自動（再送）と手動（再度アップロード）どちらを想定していますか？
